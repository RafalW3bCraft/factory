# Pocketful Dark Factory

## Purpose

An autonomous multi-agent software factory operating through BAND Desktop.

## Seats

1. Architect
2. Builder
3. Verifier
4. Reviewer

## Operating Model

Specification
→ Planning
→ Implementation
→ Independent Verification
→ Review
→ Repair when necessary
→ Reverification
→ Acceptance

## Human Interaction

For the recorded production run, the human supplies the stage task.
Agents perform planning, implementation, verification, repair and review
without manual steering.

## Evidence

Each stage produces:
- implementation
- tests
- verification results
- review decision
- reproducible commands
- failure/recovery evidence where applicable
