# BAND Room Export

Place the raw, unedited `room.json` session export here (and at the repository root as `room.json`).

## How to export from BAND Desktop:
1. In BAND Desktop, locate the room where the factory ran.
2. Click the room's **⋮** menu and choose **"Open in Band"** (opens the web console).
3. In the console, click **⋮** -> **Download** -> **"Download full session"**.
4. Save the downloaded file as `room.json` in this directory (`band-room-export/room.json`) and at the repo root.
