## 2. Defect Register

### D1 — Hard-coded personal paths in dispatch files (CRITICAL)
**File:** `dispatch/pocketful-all-stages.md`, `dispatch/toy-all-stages.md`
**Evidence:** Every path references `/home/sp3ct0r/band-work/`. If run on any other
machine or with a different result repo, Foreman sends Smith to nonexistent paths.
**Impact:** Submitted run will fail immediately.

### D2 — `RESULT_REPO` env-precedence bug (HIGH)
**File:** `start-factory.sh` line 69
**Evidence:** `.env` sourced with `set -a` before `RESULT_REPO` check; if `.env`
defines `RESULT_REPO`, it silently overrides any exported value. No argument path,
no warning.
**Impact:** `export RESULT_REPO=X && ./start-factory.sh` silently uses `.env` value.

### D3 — RUNBOOK hard-codes personal paths (HIGH)
**File:** `RUNBOOK.md` — 48 occurrences of `/home/sp3ct0r`
**Impact:** RUNBOOK unusable on any other machine.

### D4 — Missing example files (MEDIUM)
No `.env.example`, no `agent_config.example.yaml`.
**Impact:** New users cannot know what fields to populate.

### D5 — RUNBOOK `tee` without `mkdir -p logs/` (MEDIUM)
**File:** `RUNBOOK.md` Phase 1 — `tee logs/smoke-foreman.log` before `logs/` exists.
**Impact:** Phase 1 smoke test fails if `logs/` doesn't exist yet.

### D6 — No mandate hash verification in preflight (MEDIUM)
**File:** `preflight.sh` — checks header lines only, not content hashes.
**Impact:** Silently drifted mandate passes preflight.

### D7 — All seats use the same `$MODEL` variable (MEDIUM)
**File:** `start-factory.sh` line 150 — all seats get the same `$MODEL`.
The run_seat.py model-guard is never hit if mandates differ.
**Impact:** Per-seat model selection from mandate is not honoured.

### D8 — No per-seat git worktrees (LOW for Track A, CRITICAL for Track B)
All seats share same `RESULT_REPO` checkout.
**Impact:** Smith commits while Inspector reviews.

### D9 — No supervisor / health-check loop (LOW for Track A)
**File:** `start-factory.sh` — crashed seats not restarted.

### D10 — No budget enforcement (LOW for Track A)

### D11 — OpenCode runs with broad host permissions (MEDIUM)
`opencode serve` has full user filesystem access.

### D12 — `.gitignore` missing common entries (LOW)
Missing: `logs/`, `*.log`, `checks/`, `dispatch/rendered/`, caches, `.DS_Store`.

### D13 — RUNBOOK `source .env` without `set -a` (MEDIUM)
**File:** `RUNBOOK.md` Phase 1 Terminal A: API key loaded but not exported to children.

### D14 — FACTORY.md template has `TBD` and placeholder URLs (MEDIUM)
Clone URLs: `<kickoff-repo>`, `<this-repo>`; stage table: all TBD.

### D15 — No `room.json` structure verification (LOW)
`preflight.sh` warns if missing but does not verify @handle messages.

### D16 — README setup incomplete (LOW)
Missing opencode config and harness venv setup steps.

### D17 — `extract_mandate_model` and `run_seat.py` untestable as module (LOW)
Functions not extracted to a module; no unit tests possible without subprocess.

### D18 — `stop-factory.sh` unconditional `kill -9` (LOW)
Line 37 always sends SIGKILL even if process already exited.

### D19 — `preflight.sh` uses hard-coded `$HOME/band-work/checks` (MEDIUM)
`CHECKS_BASE` not configurable.

### D20 — RUNBOOK 3b has redundant copy/commit (LOW)
Copies FACTORY.md/README.md manually after bootstrap already committed them.

### D21 — No CI configuration (LOW)
No `.github/workflows/ci.yml`, no pre-commit hooks, no linting config.
